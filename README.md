# Maser Disk Analysis

Computing project in C, for analyzing the physical properties and gravitaional stability
of H2O megamaser disks around smbhs.

## Features

- Disk surface density and mass
- Rotational velocity
- Angular velocity
- Orbital period
- Epicyclic frequency
- Toomre parameter
- Observational data processing/
- Visualization/plots

## Reference
Deepshika et al. (2026)
Analysis of H2O megamaser disks and supermassive black hole masses
